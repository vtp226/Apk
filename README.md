# تغییر تعداد اسلات بازیکن/AI از ۱۰ به ۲۰

این محدودیت (۱۰ اسلات) بر خلاف تنظیمات مود، توی **کد کامپایل‌شده‌ی خودِ برنامه** (classes.dex) هاردکد شده،
نه توی یه فایل .ini قابل ویرایش. برای همین باید برنامه رو دیکامپایل، پچ، و دوباره کامپایل کنیم.
چون فقط گوشی داری، همه‌ی این مراحل رو GitHub Actions (سرورهای رایگان گیت‌هاب) برامون انجام می‌ده.

این کار دو فاز داره:
1. **فاز ۱ (همین الان):** پیدا کردن دقیق جایی که عدد ۱۰ توی کد نوشته شده.
2. **فاز ۲ (بعداً):** پچ کردن همون قسمت و ساختن APK نهایی.

---

## مرحله ۱: ساخت ریپازیتوری روی گیت‌هاب (از گوشی)

1. اپ GitHub (یا مرورگر گوشی، سایت github.com) رو باز کن و لاگین کن.
2. یه ریپازیتوری جدید بساز (دکمه‌ی "+" → "New repository")، مثلاً به اسم `rw-mod`.
   - **Private** بگیرش (چون فایل بازی داخلشه).
3. وارد ریپو شو → **Add file → Upload files**.
4. فایل `game-original.apk` که همینجا برات فرستادم رو آپلود کن (حجمش حدود ۲۴ مگابایته، مشکلی نداره).
5. دوباره **Add file → Create new file** بزن.
   - توی قسمت اسم فایل، دقیقاً این مسیر رو بنویس:
     `.github/workflows/1-find-slot-limit.yml`
     (گیت‌هاب خودش پوشه‌های `.github` و `workflows` رو می‌سازه)
   - محتوای فایلی که برات فرستادم (`1-find-slot-limit.yml`) رو کامل کپی/پیست کن توش.
   - **Commit new file** بزن.

## مرحله ۲: اجرای Action

1. توی ریپو برو تب **Actions**.
2. یه workflow به اسم "1 - Find player slot limit" می‌بینی → بزن روش.
3. سمت راست دکمه‌ی **Run workflow** رو بزن (و بعد دوباره دکمه‌ی سبز Run workflow رو تأیید کن).
4. چند دقیقه صبر کن تا اجرا تموم بشه (رنگ سبز ✅ می‌شه).

## مرحله ۳: گرفتن نتیجه و فرستادنش به من

1. روی همون اجرای تموم‌شده (run) بزن.
2. پایین صفحه، بخش **Artifacts** رو پیدا کن — دو فایل می‌بینی:
   - `search-results`
   - `matched-smali-files`
3. هر دو رو دانلود کن (فایل zip می‌شن).
4. فایل `search_results.txt` رو باز کن، محتواش رو کامل برام کپی/پیست کن اینجا.
   - اگه فایل‌های `matched-smali-files` هم چیزی داشت (خالی نبود)، بگو تا بگم کدومشون رو برام بفرستی.

با این اطلاعات دقیقاً پیدا می‌کنم کجای کد باید عوض بشه، و فاز ۲ (پچ + ساخت APK نهایی + امضا کردنش) رو برات آماده می‌کنم.
